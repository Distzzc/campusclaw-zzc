## Purpose

为浏览器端和 API 提供统一的显式令牌认证契约，使访问凭证可校验、可过期、可撤销，并确保未认证请求无法读取受保护数据。

## ADDED Requirements

### Requirement: 用户可以通过账号密码获取访问令牌
系统 SHALL 提供登录 API，接受账号和密码，并在凭据有效时返回不透明访问令牌、令牌类型、有效时长及非敏感用户信息。系统 MUST 对无效账号和错误密码返回一致的认证失败结果，且 MUST NOT 返回或持久化明文密码或完整访问令牌。

#### Scenario: 有效凭据签发令牌
- **WHEN** 用户向登录 API 提交有效账号和密码
- **THEN** 系统返回可用于 Bearer 认证的访问令牌、有效时长和用户信息，且不返回密码

#### Scenario: 无效凭据不签发令牌
- **WHEN** 用户提交不存在的账号或错误密码
- **THEN** 系统以一致的认证失败响应拒绝请求，且不创建有效令牌

### Requirement: 受保护 API 仅接受有效 Bearer 令牌
系统 SHALL 要求受保护 API 请求通过 `Authorization: Bearer <token>` 提交有效令牌。系统 MUST 从服务端记录解析用户身份、角色和班级范围，不得信任客户端自行提供的身份或授权范围；Cookie Session 不得作为受保护 API 的认证凭证。

#### Scenario: 有效 Bearer 令牌访问 API
- **WHEN** 请求在 Authorization 头中携带有效 Bearer 令牌
- **THEN** 系统以该令牌关联的用户身份处理请求，并继续执行现有角色授权和班级隔离检查

#### Scenario: 缺少或无效令牌访问 API
- **WHEN** 受保护 API 请求缺少 Bearer 令牌、令牌格式错误或令牌无效
- **THEN** 系统返回 HTTP 401，且不返回受保护数据

#### Scenario: 仅有旧 Cookie 不构成认证
- **WHEN** 请求只携带此前登录创建的 Cookie Session，未携带有效 Bearer 令牌
- **THEN** 受保护 API 将请求作为未认证请求拒绝

### Requirement: 访问令牌必须有时效并支持登出撤销
系统 SHALL 为令牌设置有限有效期，初始有效期为 1 小时；系统 MUST 在每次受保护请求中拒绝过期或已撤销令牌。登出操作 SHALL 撤销当前令牌，令牌过期后用户 MUST 重新登录，不要求提供刷新令牌。

#### Scenario: 过期令牌被拒绝
- **WHEN** 用户使用已超过有效期的令牌请求受保护 API
- **THEN** 系统返回 HTTP 401，且不返回受保护数据

#### Scenario: 登出后令牌立即失效
- **WHEN** 用户使用有效令牌调用登出 API
- **THEN** 系统撤销该令牌，后续使用同一令牌的受保护请求返回 HTTP 401

### Requirement: 浏览器使用令牌访问受保护页面与 API
浏览器登录界面 SHALL 通过登录 API 获取令牌，并仅在当前标签页的 `sessionStorage` 保存令牌。浏览器 MUST 在受保护 API 请求中附加 Bearer 令牌；受保护页面的 HTML 外壳不得包含受保护用户或材料数据，未登录、令牌过期或令牌无效时前端 SHALL 导航至登录页。登出时浏览器 SHALL 清除本地令牌并请求服务端撤销。

#### Scenario: 浏览器成功登录并加载受保护数据
- **WHEN** 用户在登录页面提交有效凭据
- **THEN** 浏览器保存当前标签页的访问令牌、进入课堂页面，并以 Bearer 令牌加载用户及其有权访问的数据

#### Scenario: 未认证的页面外壳不泄露受保护数据
- **WHEN** 用户未登录而直接打开受保护页面 URL
- **THEN** 页面仅返回不含用户、角色、班级或材料数据的应用外壳，且前端导航至登录页面

#### Scenario: 令牌失效后浏览器重新登录
- **WHEN** 受保护 API 返回令牌失效的 HTTP 401
- **THEN** 浏览器清除当前标签页保存的令牌并导航至登录页面

#### Scenario: 浏览器登出
- **WHEN** 用户在已认证状态下选择登出
- **THEN** 浏览器请求服务端撤销当前令牌、清除本地令牌并导航至登录页面
